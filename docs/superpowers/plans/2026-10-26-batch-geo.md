# 装小果 AI 批量 GEO 工作流

Goal: 根据用户直接实现要求，把单图工具改为每关键词一组的苏州装修公司甄选图文工作流。
Architecture: 复用 Next.js 服务端；前端逐组队列，每组双并发单素材请求，避免多张 base64 合并响应过大；ZIP 在浏览器生成。

- [x] 测试优先：3/4 张图、关键词解析、任务类型、逐图配文数量、响应预算、队列并发、失败重试、取消。
- [x] API 输入增加 imageCount、task、imageIndex、真实公司资料；文本返回逐图配文，图片使用不同空间主题。
- [x] 中文批量工作台、分组预览、实时进度、停止恢复、按失败项补生成、JPEG/ZIP 下载。
- [x] 更新 README 与部署说明。
- [x] 生产构建、类型检查、浏览器工作流验证。

Ruling: 每批最多 10 个去重关键词，默认每组 4 张，可选 3 张；没有真实公司信息时提供甄选方法而非虚构排名。
Ruling: 使用现有 /workspace/zhuangxiugeo；不创建 worktree，不修改原有 GitHub 远端。
