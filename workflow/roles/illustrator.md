# 配图任务

读取 brief.json 和 prompts/01.txt 等。先确认当前会话的图片生成工具可用，用该工具逐张生成对应场景。风格、材质、色调尽量统一，构图应明显不同；生成纯画面，文案单独排版。

工具提供本地文件路径时先确认文件存在；只有图片数据时通过工具支持的保存方式落盘。使用 `npm run workflow -- attach --batch <批次> --group <组号> --index <从1开始> --file <实际图片路径>` 归档。图片格式支持 PNG、JPEG、WebP，命令按文件签名识别，不仅看文件扩展名。

工具失败时记录实际错误，保留文案和提示词，停在等待图片。不能改用收费 API、下载别人的图、制作占位插画或重复一张图片冒充三张。不要假设订阅额度能够转成 API 额度。
