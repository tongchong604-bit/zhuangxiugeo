# 文案任务

2026-10-30最新多页轮播要求优先：图数、公司数与文体按当前选题安排，不固定三张或三家。用户提供短钩子发布文案＋多页公司详解参考时，TXT保持简短、自然、有吸引力，详细介绍放在各家公司图片中；不强制复制图内长文。整篇仍不超过1000字，不冒充亲测、独立排名或真实口碑调查。下方三卡字段只用于旧模式兼容。

带字三卡模式先读 `workflow/production-preferences.md`：顺序为关键词封面、公司选择参考、同一关键词的深入比较或选择判断；不套用下文空间效果图的固定场景和纯图规则。不同组的图文必须体现明显差异。

本模式“生成N篇”默认是N套完整图文。写完N篇文案后，还必须完成每篇三张新生成带字图的配图与审核，不能用仅有TXT的交付结束任务；用户明确只改文字或不要图片时除外。

带字三卡的对外文字只交付每组一篇完整发布文案（含标题、正文和话题标签，不超过1000字），不写图外逐图配文。图片内部的标题、介绍、知识点和提醒另行形成制作排字稿，仅供配图与审核使用，不向用户输出“图1：……图2：……”或逐图配文文件。下文的旧空间图JSON字段只用于兼容原工具，不作为营销三卡的交付要求。

文章直接面向业主，自然写公司介绍与装修内容，不出现“本组列出”“进一步了解的名单”“官网展示”“转化成面谈问题”等制作或调研说明。正文不加“配图为AI设计示意”，来源和生成记录留在内部档案；不得编造亲测、名次、评价或公司优势。

开头用紧扣关键词的问题或顾虑抓住读者，再自然引出公司；每家讲清推荐了解的具体理由。用业主平时说话的词，不用“环节统筹、推进沟通、服务边界、具体着眼点”等报告措辞，不把三段都写成“提供……涉及……适合……比较时……”的重复模板。第三人称可以亲切、有钩子，不等于冷硬的资料汇编。

每家公司都要在TXT和公司页图内排字稿中有具体特点介绍，讲清已知服务特点、实际便利和适合需求，不能省略其他公司、只列名字或使用换名套话。图文的事实口径一致；图内可以精炼表达，但不能把完整介绍缩成没有解释的标签。缺少资料时先核实，不虚构差异。

标题问“苏州装修公司哪家好/推荐/口碑哪家好”时，文章主体直接介绍公司、可核实特点与适用需求，华家居先写，其余公司自然接续。不能把公司名当引子，然后主要写收纳、厨房或防潮；通用选公司标准也不能代替具体公司介绍。第三张也必须继续回答原关键词，深化已介绍公司的比较、适配需求或选择判断；全文结尾不引入无关装修知识。差异化通过公司组合、介绍角度和文章结构实现，不能通过偏题实现。写前明确标题的问题，写后检查三张图和文章是否都给出了对应回答。

标题改为“怎么选/怎样判断靠谱/怎么避坑”时，把公司介绍与对应选择方法、判断依据或风险应对结合起来。用户本次明确要求三篇TXT均有华家居、圣都、红蚂蚁三家公司详解和服务优势，华家居首项；不能省略公司写成纯通用攻略，也不能把品牌名或服务模式当靠谱的证明。优势只从已知服务资料合理解释，不新增质量、价格、口碑或保证。多篇同时写时，各用不同钩子、结构与语气，不能只换同义词。

读取本组 brief.json 和 company.json；后者或任务需求有更新时应新建批次，避免混用资料。

输出 copy.json，字段为 title、copies（恰好 3 条）、imageCaptions（恰好 3 或 4 条，等于图片数）、consultation。每条正文约 100–180 中文字，三个角度分别为甄选方法、生活设计需求、咨询前准备；标题直答关键词，语气自然，避免堆砌关键词。

图片与配文顺序固定：客厅、餐厅、卧室、厨房（3 图时无厨房）。配文描述设计与生活功能，不把场景当作公司能力的事实证据。资料不足时不凭空提供装修公司名称、榜单或“第一名”；可说明应如何实地了解、核实合同和交付范围。

使用 `workflow/templates/copy.example.json` 的结构。执行 `npm run workflow -- copy --batch <批次> --group <组号> --file <JSON路径>` 保存并验证。只写自己负责的组，不审核自己的产出为通过。
