# 审核任务

带字三卡模式先读 `workflow/production-preferences.md`：顺序为关键词封面、公司选择参考、同一关键词的深入比较或选择判断；不套用下文空间效果图的固定场景和纯图规则。不同组的图文必须体现明显差异。

带字三卡检查：内容直接排在图内且可读；每组对外交付仅三张图和一篇1000字内的完整发布文案，不附“图1/图2/图3”的图外说明或逐图配文文件。内部排字稿只用于制作审核，不算成品。

逐家公司对照TXT和公司页成图：两处都须有具体特点、服务便利与适合需求的实质介绍，事实口径一致，不只列名称或空泛标签；不能只详写华家居、其余一句带过，不能三家公司换名套写。特点必须有资料依据，不能为区别而臆造质量、价格、口碑或承诺。首图仍无公司名单。

用户说“生成N篇”时，检查N套是否都有三张真实新图与一份完整TXT。只有文案、提示词或内部排字稿不算图文完成。各图与各篇标题对应，前后版本的旧图片不能自动沿用为新批次的生成结果。

首图若出现具体公司名字、名单或公司介绍，必须交回重做；这些内容从第二张开始展开，第三张可依据已介绍的公司资料继续比较。审核风格差异时实际对照旧图与同批其他套，核查摄影/图形/实物等视觉类型、空间组织与阅读顺序，不能只根据配色变化判为不同模板。

第三张逐段核查是否直接回答用户的完整关键词。关键词是“苏州吴中区装修公司哪家好”时，第三张须继续公司比较、适配需求或选择判断；“旧家具留不留”等独立装修知识必须判为跑题并交回修正。不得仅因为它属于装修话题、标题含吴中，或文案结尾提过它就判为相关。审核记录须写明第三张如何帮助回答原关键词。

实际阅读 copy.json、brief.json 和全部配图，不以文件存在替代内容检查。

逐项检查：标题与关键词一致；三条正文各有用途；逐图配文与客厅/餐厅/卧室/厨房顺序一致；未把设计图说成实拍案例；没有无依据的公司名称、排名、资质、口碑、价格或保证推荐；图片能打开且场景不同、无明显多余文字或严重结构错误。

检查不通过：指出具体组号、图片序号或文案字段，交回对应任务修正，不运行审核通过命令。

通过后记录具体结论，例如“已检查三张不同空间图与逐图配文；未引用未经核实的公司排名；图片均标为设计示意”，运行 `npm run workflow -- review --batch <批次> --group <组号> --note <结论>`。审核指纹绑定当前文案、brief 与图片字节；素材变更后自动失效，需要重审。
